## 1. Что такое Чат Аура

**Локальный ИИ-чат.** Языковая модель работает на вашем компьютере (или на одном сервере локальной сети), диалоги не покидают машину. Полностью офлайн после скачивания моделей — в интернет уходит только поисковый запрос, и то если вы сами включили поиск.

Ключевая особенность: **один сервер — много клиентов.** Модель и вычисления — на одном постоянно включённом ПК, пользователи — с любых устройств сети: компьютеров, ноутбуков, планшетов, телефонов. Каждый со своими чатами, памятью и настройками. Для домашнего использования всё это выглядит как обычная локальная программа.

## 2. Где запустится, а где нет

**Запустится:**
- Windows 10/11 (64 бит) — серверная часть. Установщик один на всех.
- Клиенты — любые устройства с браузером (Windows, Android, iOS, Linux, macOS): заходят по адресу сервера.
- Процессор любой x86-64 примерно от 2013 года.
- Видеокарта не обязательна: без неё всё считает CPU (медленнее, но работает). С GPU — быстрее:
  - NVIDIA: GTX 16xx, RTX 20/30/40/50xx (CUDA);
  - AMD Radeon, Intel Arc/UHD — через Vulkan 1.2+;
  - неизвестная видеокарта — автоматически процессор.

**Не запустится:**
- 32-битные Windows, Windows 7/8 и старше.
- Не всякий файл `.gguf` совместим с llama.cpp (например, аудио-модели — нельзя).
- Голос (микрофон) на клиентских устройствах работает **только по HTTPS** (требование браузеров, обходится сертификатом — см. раздел 11).

**RAM сервера:** 8 ГБ — модели 4B, 16 ГБ — 12B, 32 ГБ — 27B. **Диск:** 1 ГБ программа + 3–16 ГБ модели.

## 3. Установка и первый запуск

1. Запустите `CHAT_AURA_Setup.exe`. Прав администратора не требуется; по умолчанию ставится в `C:\Users\<имя>\AppData\Local\KVMSOFT\CHAT_AURA`.
2. В меню «Пуск» — два ярлыка: **«Запуск сервера ЧАТ АУРА»** и **«Открыть чат (браузер)»**. Первый запуск сам открывает браузер. Окна у сервера нет — это нормально, работа идёт через браузер.
3. Откроется **окно загрузки моделей** (всегда доступно по адресу `/setup`): слева описание, справа — «Установленные модели», «Доступные для скачивания», «Голос».
4. Радиокнопкой отметьте одну языковую модель и нажмите **«К чату»**. Скачивание можно приостанавливать и продолжать с места обрыва. Голосовые модули («Распознавание речи» и «Озвучка») необязательны: без них не работают только голосовые функции.
5. После загрузки модели вы попадёте в чат.

## 4. Свои модели

Положите файлы `.gguf` в папку `models\llm\` рядом с exe (на сервере). На `/setup` они появятся со статусом «Своя модель». Файл вида `mmproj-*.gguf` автоматически распознаётся как проектор изображений.

## 5. Интерфейс чата

**Шапка** (справа значки): ☾/☀ — тема (тёмная/светлая, запоминается); палитра — акцентные темы (NEON/TEAL/EMBER/GRAY); RU/EN — язык интерфейса; **?** — «О программе»; **⏻** — полная остановка Ауры.

**Строка Ауры** (под шапкой): андроид меняет цвет — фиолетовый «жду», оранжевый «думаю», зелёный «отвечаю»; бары-гистограмма оживают, пока Аура работает; **микрофон** по центру — ручная запись; кольцо со счётчиком «N с» — окно ожидания следующего вопроса (30 сек после ответа).

**Нижняя бегущая строка** — статусы моделей: LLM, mmproj, распознавание речи, озвучка (зелёный/красный квадратик — загружена/нет), слои GPU.

**Сообщения**: ваши — справа, Ауры — слева; под каждым пузырём значок 📋 — копировать текст. Кнопка **■ «Стоп»** во время ответа прерывает генерацию и озвучку — уже выданный текст сохраняется с пометкой «— генерация остановлена —».

**Левая панель:**
- **НАСТРОЙКИ**: «Свободные руки», стриминг ответа, озвучка ответа, поиск в интернете; селект «Поисковый API» (бесплатные движки / Tavily / Brave) и поле ключа.
- **ИНФОРМАЦИЯ**: кольца «Контекст модели» и «Ответ» (ваш лимит ответа), полоса «Контекст диалога» (оранжевый сегмент — служебный промпт, в бюджет не входит), «Скорость: X ток/с · Y с» — скорость генерации и полное время ответа.
- **МОИ ЧАТЫ**: «＋ Новый чат»; меню ⋯ у чата: Экспорт, Переименовать, Удалить. Имя даёт первое сообщение.

**Поле ввода**: 📎 — прикрепить изображение; Enter/самолётик — отправить; микрофон — голосовой ввод; ⚙ — «Параметры ИИ»: выбор модели и mmproj, слайдеры (ядра CPU, слои GPU, контекст, температура, Max Tokens и др.), настройки vision.

## 6. Голосовое общение

- Распознавание: **GigaAM** (приоритет, точнее) или **Vosk** (резерв). Озвучка: **Silero**.
- **Ручной микрофон**: значок в поле ввода → говорите → пауза ~3 секунды — фраза уходит на распознавание. Начало печати текста микрофон отключает.
- **«Свободные руки»**: скажите ключевое слово «Аура», затем вопрос. После ответа 30 секунд открыто окно следующего вопроса — кольцо со счётчиком вокруг микрофона. Таймер стартует после окончания озвучки (если она включена).
- Решение об озвучке фиксируется в момент отправки: включили тумблер посреди ответа — этот ответ останется без озвучки (иначе Аура слушала бы саму себя).
- Состояние озвучки/распознавания всегда видно в бегущей строке внизу экрана.

## 7. Словарь произношения (tts_dict.json)

Всякая речь Ауры перед синтезом проходит через словарь произношения: **файл `static\tts_dict.json`** рядом с программой. Правится обычным текстовым редактором — без пересборки, применяется при обновлении страницы.

Три секции:
- **abbr** — сокращения с точками: `"т.е.": "то есть"`;
- **acr** — акронимы и символы: `"NHL": "эн-эйч-эл"`, `"км/ч": "километров в час"`, `"₽": "рублей"`. Латинские капсом заменяются с учётом регистра (`IT` не тронет английское «it»);
- **stress** — **ударения**: знак `+` перед ударной гласной: `"договор": "догов+ор"`.

Уже внутри ~180 записей: спорт (ФИФА, ИИХФ, НХЛ, УЕФА, НФЛ, НБА, КХЛ…), IT (API, URL, GPU, HTTP…), организации (СССР, ООН, НАТО, МВД…), единицы и валюта. Также автоматически: ссылки не читаются, даты «06.11.2026» звучат «шестое ноября 2026 года». Слышите неверное ударение или незнакомое сокращение — дописывайте в файл.

## 9. Поиск в интернете

- **Бесплатные движки** — без ключа.
- **Tavily** — 1000 запросов/мес бесплатно (app.tavily.com, регистрация через VPN, карта не нужна).
- **Brave Search** — 2000 запросов/мес (brave.com/search/api).
При пустом ключе или ошибке Аура сама возвращается на бесплатные движки. Пока идёт поиск, в чате видна временная заметка «🔍 Ищу в интернете…» — она исчезает с первыми словами ответа.

## 10. Контекст, память, обрезка

- **Контекст диалога** — ваш бюджет (параметр «Контекст», по умолчанию 2048 токенов). Служебный промпт в этот бюджет **не входит** — в полосе «Контекст диалога» он показан оранжевым сегментом.
- Достигнув лимита, старые реплики **физически удаляются** из истории — счётчик не растёт бесконечно.
- Аура может запоминать факты о вас («[ПАМЯТЬ:]» — видно только ей, в чат не выводится): имя, предпочтения. Просит назваться, если имени не знает.
- Если имени нет в памяти — Аура спросит его при первом приветствии, а не будет писать «Привет, [Имя]».

## 11. Локальная сеть: один сервер — много клиентов

1. Установите Ауру на серверный ПК (включён постоянно).
2. Разрешите порт **5000** (или ваш из `config.json`) в брандмауэре: «Правила для входящих → Создать правило → Порт → TCP 5000».
3. Узнайте IP сервера: `ipconfig` (например, 192.168.1.50).
4. Клиенты открывают `http://192.168.1.50:5000`. Текст, картинки, чаты — работают сразу, без сертификатов.
5. **HTTPS для голоса на клиентах**: положите в папку `ssl` рядом с exe пару `cert.pem` + `cert-key.pem` — сервер сам поднимется на `https://`. Самоподписанный сертификат подойдёт (браузер предупредит — принять).
6. Ярлык «Открыть чат» по умолчанию ведёт на `127.0.0.1` — на клиентских устройствах создайте ярлык на адрес сервера.

## 12. Администрирование сети

**Главное правило:** сервер загружает ОДНУ языковую модель на всех. Модель и параметры генерации — зона администратора; личные предпочтения (тема, голос, стрим, поиск) — у каждого свои.

- **Кто администратор:** список `admin_uuids` в `config.json`. Свой UUID админ видит в чате (клик по ID — копия). **Список пуст = все админы** — так работает одиночный домашний режим, ничего настраивать не нужно.
- **Администратор** видит всё: «Параметры ИИ» (модель, слайдеры), «Поисковый API», окно `/setup` со сменой и скачиванием моделей.
- **Обычный пользователь сети:** тема, свои чаты, текст и картинки, тумблеры «Свободные руки»/стрим/озвучка/поиск (личные). «Параметры ИИ» и «Поисковый API» **не видит**, модель сменить не может (сервер ответит 403), «тяжёлые» настройки сервер вырезает из его сохранений.

## 13. UUID — ваша единственная «учётная запись»

Регистрации и паролей нет. Ваш идентификатор — **UUID**, хранится в браузере (localStorage), показан в чате (клик — скопировать).

- **Сохраните UUID в надёжном месте** — это единственный ключ ко всем вашим чатам и памяти.
- Слетел браузер/кэш/ОС — UUID сменится, и сервер вас не узнает: прежние чаты недоступны. Автовосстановление невозможно (иначе любой смог бы присвоить чужую переписку).
- **Восстановление через администратора** (пользователь сообщает СТАРЫЙ и НОВЫЙ UUID):
  1. **Сервисный роут.** В `config.json` задайте `"admin_token": "<длинная случайная строка>"`, перезапустите сервер и выполните:
     `curl -X POST http://127.0.0.1:5000/api/admin/reassign_uuid -H "Content-Type: application/json" -d "{"token": "<ключ>", "old_uuid": "<старый>", "new_uuid": "<новый>"}"`
  2. **Вручную в БД** (сервер остановлен), файл `%LOCALAPPDATA%\KVMSOFT\CHAT_AURA\instance\site.db` любым SQLite-редактором:
     ```sql
     UPDATE chat_history SET uuid='<новый>' WHERE uuid='<старый>';
     UPDATE chat_sessions SET user_uuid='<новый>' WHERE user_uuid='<старый>';
     UPDATE user_memory SET uuid='<новый>' WHERE uuid='<старый>';
     ```

## 14. Где что лежит

- Программа и модели: папка установки (`…\AppData\Local\KVMSOFT\CHAT_AURA\`, рядом с exe — `models\`; словарь произношения — `static\tts_dict.json`).
- Настройки, лог, база: `%LOCALAPPDATA%\KVMSOFT\CHAT_AURA\` — `config.json`, `aura.log`, `site.db`. Обновление программы их не трогает.

## 15. Обновление и удаление

- **Обновление**: установите поверх — настройки, чаты, модели и словарь сохранятся.
- **Удаление**: через «Приложения». Полное стирание — вручную удалить `%LOCALAPPDATA%\KVMSOFT\CHAT_AURA`.

## 17. Если что-то пошло не так

- **Не работает озвучка в exe** → в `models\silero\` должны лежать и `v5_5_ru.pt`, и `torch_src.zip`.
- **Голос не работает на клиенте** → открывайте чат по `https://` (раздел 11).
- **Что-то странное** → журнал: `%LOCALAPPDATA%\KVMSOFT\CHAT_AURA\aura.log`.
- **Порт занят** → смените `"port"` в `config.json`, поправьте ярлык «Открыть чат».
- **Остановить сервер** → кнопка ⏻ в шапке чата.
- **Страница не открывается** → сервер запущен (ярлык «Запуск сервера»)? Адрес вручную начинается с `http://` (или `https://` при наличии сертификатов) — браузер может сам подставлять https.
